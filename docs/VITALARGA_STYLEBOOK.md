# Vitalarga stylebook operativo

Fuente: `Stylebook Vitalarga premium.zip` aportado por Daniel el 2026-08-30.

Este documento resume los tokens útiles para el producto. El stylebook se trata
como referencia de marca, no como fuente de instrucciones legales, médicas ni
editoriales.

## Identidad

- Nombre público: Vitalarga.
- Dominio canónico: `https://www.vitalarga.com`.
- Posicionamiento visual: clínico, sereno, editorial y premium.
- Logotipo: isotipo circular con aro oro cálido y centro sólido, acompañado del
  wordmark Vitalarga en serif editorial.

## Tipografía

- Titulares y marca: Newsreader.

## Uso editorial seguro

El stylebook original contiene algunos ejemplos de copy orientativos que no se
deben trasladar literalmente al producto porque pueden rozar límites operativos:

- Evitar "mejores clínicas".
- Evitar "comparar clínicas" si sugiere superioridad o calidad asistencial.
- Evitar badges como "Premium" aplicados a clínicas.
- Evitar "reservar valoración" si Vitalarga no gestiona reservas.
- Mantener siempre: guía informativa, sin rankings, sin publicidad y sin
  recomendaciones médicas.

Para decisiones dudosas, usar `docs/VITALARGA_LIMITES_OPERATIVOS.md`.
